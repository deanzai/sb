# sing-box 深度安全加固与防回国流量增强版 (sb)

本项目基于开源项目 `sing-box-yg` 进行全面安全审计、漏洞加固及核心功能增强。
支持 **Vless-reality-vision、Vmess-ws(tls)+Argo、Hysteria-2、Tuic-v5、Anytls** 五协议共存，并内置**屏蔽 VPS 回国流量防御模块**。

---

## 🚀 快速开始

在支持的 Linux 服务器（Debian、Ubuntu、CentOS、Alpine 等）以 `root` 权限执行以下命令即可一键运行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/deanzai/sb/main/sb.sh)
```
或者使用 `wget`：
```bash
bash <(wget -qO- https://raw.githubusercontent.com/deanzai/sb/main/sb.sh)
```

脚本快捷方式：运行 `sb` 即可随时唤出管理主菜单。

---

## 🛡️ 核心安全加固与改进

原版一键脚本在网络配置和凭证管理上存在多项中高危隐患，本项目进行了彻底的防御性加固：

1. **废弃暴力清空防火墙（Firewall Hardening）**：
   - 彻底移除了原版中无脑执行 `ufw disable`、`setenforce 0`、`iptables -F` 以及清空全部安全链的逻辑；
   - 改造为**按需安全放行**：仅针对 sing-box 实际启用的业务端口（TCP/UDP）安全放行，完整保留服务器现有的 SSH 防护、安全基线与 fail2ban 防爆破机制。

2. **清除证书绕过漏洞（SSL/TLS Enforcement）**：
   - 全面剔除所有 `curl --insecure` 参数，强制启用双向完整证书链验证，防止脚本更新和依赖拉取时遭遇中间人劫持（MITM）或恶意替换。

3. **敏感凭据权限收紧（Least Privilege）**：
   - 统一收紧 `/etc/s-box` 目录权限为 `700`，并将包含 UUID、私钥、Argo Token、Telegram Token 的文件权限收敛为 `600`，杜绝系统提权或同机低权限进程窃取节点凭证。

4. **重构脆弱的写死行号替换（JSON Engine Refactoring）**：
   - 淘汰原版大量易崩坏的 `sed -i "184s/.*/..."` 写死行号配置逻辑，全面改用基于结构化 JSON 的幂等解析引擎，彻底避免因配置文件微调导致 JSON 损坏使 sing-box 无法启动。

## 🚫 屏蔽 VPS 回国流量功能（防全局代理穿透）

### 为什么需要阻断回国流量？
当客户端开启**全局代理模式（Global）**或客户端分流规则未生效时，访问中国大陆网站（百度、微信、网银、国内政企等）的所有流量都会涌入境外 VPS。境外 VPS 进而代表用户直接向国内服务器发起建连：
- **触发封锁**：境外 VPS 频繁与大陆境内 IP 大流量建连，极易被 GFW 主动探测并导致 VPS IP 遭阻断封锁；
- **合规审计**：绕行国内流量增加 IDC 违规风险；
- **体验极差**：境外来回绕路导致数百毫秒高延迟与带宽浪费。

### 核心机制
- **双内核无缝兼容**：
  - **sing-box 1.11+ 内核**：持久化本地规则集 `geosite-cn.srs` 与 `geoip-cn.srs`，通过 local rule_set 在路由层优先匹配中国大陆域名与 IP 并阻断出站；
  - **sing-box 1.10 内核**：通过 `geosite: cn` 与 `geoip: cn` 拆分出独立 block 规则拦截。
- **开箱即用与交互开关**：
  - 全新部署默认开启屏蔽保护；
  - 主菜单新增 **选项 17**：`17. 屏蔽VPS回国流量设置 【当前状态：已开启/已关闭】`，支持一键切换并自动热重载生效。
